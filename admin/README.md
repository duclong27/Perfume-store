Perfume Store – Admin Dashboard (Frontend)

Admin dashboard for managing products, categories, orders, and monitoring system
statistics in the Perfume Store e-commerce platform.

Overview

This frontend application provides administrative features including product management,
order approval workflows, and dashboard analytics.
It communicates directly with the Admin Backend (Core API) using secured REST APIs.
