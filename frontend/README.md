Perfume Store – Customer Web App (Frontend)

Customer-facing web application for browsing products, managing the shopping cart, and
placing orders in the Perfume Store e-commerce system.

Overview

This frontend application handles the complete customer shopping flow, from product
discovery to checkout.
It communicates with the Customer Backend (shop-bff) via REST APIs.
